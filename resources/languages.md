# Languages

A language is T2-cost by nature (1–3 years to real use), so it's resourced by
*method* here, not by any one tongue. Pick the language for pull or utility;
apply the same method to any of them.

## Method (works for any language)
- **Survey of how:** *Fluent Forever* — Gabriel Wyner. The best single book on
  *how* to learn a language as an adult: pronunciation first, spaced
  repetition, images over translations, no grammar drills. Read it before
  choosing tools.
- **Canon of theory:** Stephen Krashen's *input hypothesis* (his *Principles
  and Practice in Second Language Acquisition* is free online) — comprehensible
  input is the engine; everything else is scaffolding.
- **The daily loop:**
  1. Spaced repetition (Anki) for vocabulary and sentences — the same SRS
     habit the whole agenda runs on.
  2. Massive comprehensible input — graded readers, then real books;
     podcasts and shows with subtitles in the target language.
  3. Speaking early and often — italki or a tutor from month one; output
     forces the gaps into view.

## Tools (durable, not fads)
- **Anki** — the SRS backbone.
- **Language Reactor / LingQ** — turn native video and text into input you can
  actually parse.
- **A human tutor** (italki, community classes) — the one irreplaceable
  resource; conversation is the feedback loop.
- **A good grammar reference** for the specific language — consult, don't study.

## Sequencing over the decades
- **Decade 1:** one language to real fluency. Depth beats collection; a single
  fluent second language reshapes how you think and reads half a culture's
  canon in the original.
- **Decade 2+:** further languages if pull persists — each easier, since
  method and SRS discipline transfer even when vocabulary doesn't.

## Note on the classical languages
If your curiosity runs toward the canon (philosophy, literature, religion,
history clusters), a reading knowledge of Latin or Ancient Greek unlocks
primary sources directly. *Lingua Latina per se Illustrata* (Hans Ørberg) is
the famous, near-magical way into Latin; Athenaze for Greek.
