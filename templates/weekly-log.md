# Weekly Log — YEAR

> One file per year, one row per week (`log/<year>-weekly.md`). Five minutes,
> same time every week (Sunday evening works). The log's job is to make drift
> visible within weeks instead of years — it feeds the annual review, so
> honesty beats completeness. An "empty week" row is a valid, useful entry.

Fill each row with a few words, not paragraphs:

| Wk | Practiced (deliberately) | Built / wrote | Read / learned | SR streak? | One-line note |
|----|--------------------------|---------------|----------------|------------|---------------|
| 1  |                          |               |                | ☐          |               |
| 2  |                          |               |                | ☐          |               |
| 3  |                          |               |                | ☐          |               |
| 4  |                          |               |                | ☐          |               |

*(extend to 52 rows as the year goes — or add four rows a month; whatever you'll actually do)*

## Monthly pulse (last log of each month, one extra minute)

- Hours on big investment #1 vs. claimed: roughly on / under / off
- Hours on big investment #2 vs. claimed: roughly on / under / off
- Any habit lapsed ≥2 weeks? → restart it *this week*, at half size if needed.
